# Generate a Multiplication Table
## Description
Create a Python program that accepts a number from the user and generates its multiplication table up to a specified limit.
## Objective
To practice Python loops and formatted output.
## Tools
- Python 3
- Online Python Compiler
## Deliverables
- Multiplication table program.
- Output for at least three different numbers.
## Features
- Accepts a number from the user.
- Allows the user to specify the multiplication table limit.
- Uses a `for` loop to generate the table.
- Displays the multiplication table in a clear format.
## How to Run
1. Open an online Python compiler or a Python editor.
2. Copy the Python program into the editor.
3. Run the program.
4. Enter the number for which you want the multiplication table.
5. Enter the required table limit.
6. View the generated multiplication table.
## Sample Input
```text
Enter a number: 5
Enter the table limit: 10
```
